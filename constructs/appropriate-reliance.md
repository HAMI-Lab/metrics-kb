# Reliance on AI: appropriateness

> Whether people follow the system when it is right and override it when it is wrong.

## 1. Definition
Reliance is appropriate when a person accepts correct advice and rejects incorrect advice. Over-reliance is following wrong advice; under-reliance is rejecting right advice [schemmer2023; cabitza2023].

## 2. Boundaries
It needs the right answer for each case, so it can be judged only where ground truth exists.

## 3. Narrower constructs
Over-reliance and under-reliance are its two failure modes, each with its own rate.
