# User characteristics

> Properties of the user alone, independent of a particular system or task.

## 1. Definition
What a person brings to any task: knowledge, skills, literacies, expertise, and stable attitudes and traits.

## 2. Boundaries
Unlike [task characteristics](task-characteristics.md), they are measured without the system under evaluation, typically with tests or questionnaires. Unlike [system characteristics](system-characteristics.md), they belong to the person.

## 4. Metrics
Tests and standardized questionnaires. In evaluations these numbers usually describe who the participants are (to check the sample, or to see whether a system works better for some users than others). They become outcomes when a system aims to change them, for example by teaching.
