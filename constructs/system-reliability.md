# System reliability

> Whether the system behaves correctly and keeps working as users rely on it.

## 1. Definition
The system does what it is supposed to do, consistently, without losing or corrupting the user's work.

## 2. Boundaries
Reliability failures show up as usability problems, but their fixes are engineering fixes, so they are kept apart from [usability](usability.md).
