# Resource cost

> What it costs to run the system: money, compute, energy.

## 1. Definition
The resources a system consumes to produce its outputs, such as dollars, tokens, compute time, energy and emissions [kapoor2025; patterson2021].

## 2. Boundaries
It is a property of the system alone, measurable without a user, so it sits under system characteristics. It is not part of performance: a cheaper system is not a better-performing one, but cost and performance are traded off [kapoor2025].
