# Task performance

> How well, and at what cost, a user working with a system reaches the goal.

## 1. Definition
The outcome a user and system achieve together on a task, and the resources spent to achieve it.

## 2. Boundaries
It excludes how the user feels about the task (that is part of [usability](usability.md)). It differs from [system performance](system-performance.md) and component performance such as [retrieval performance](retrieval-performance.md), which are measured without a user pursuing a goal.

## 3. Narrower constructs
Effectiveness and efficiency are the two parts named in ISO 9241-11 [iso9241-11]. They can trade off (faster but less accurate) and correlate only modestly across studies [hornbaek2007], so report both.
