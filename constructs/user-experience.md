# User experience

> How using a system feels to the person: pleasing, engaging, emotionally positive or not.

## 1. Definition
The person's perceptions and responses from using a system, beyond whether it is usable: for example attractiveness, stimulation, novelty and emotional reaction [laugwitz2008].

## 2. Boundaries
Overlaps with [usability](usability.md), especially perceived usability; user experience questionnaires usually include pragmatic (usability-like) scales next to hedonic ones [laugwitz2008]. It needs a user and a system together, so it is a task characteristic.

## 3. Narrower constructs
Emotional response and aesthetic pleasure are narrower aspects; others (stimulation, novelty) are covered by UEQ scales without their own pages.
