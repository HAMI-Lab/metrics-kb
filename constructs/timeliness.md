# Retrieval effectiveness: timeliness

> Whether a retrieved item is current enough for the user's need.

## 1. Definition
How up to date an item is relative to what the user needs. Currency is one of the criteria users apply beyond topic [barry1998].

## 2. Boundaries
An item can be topically relevant and still outdated. Timeliness depends on the need: news needs fresh items; history does not.
