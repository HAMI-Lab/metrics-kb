# System performance

> How well the system itself works: the quality, speed, and dependability of what it does.

## 1. Definition
Performance of the system as measured without a user pursuing a goal: the quality of its outputs, how fast it responds, how efficiently it uses resources, and how reliably it works.

## 2. Boundaries
It mirrors [task performance](task-performance.md) on the task side. A system can perform well on benchmarks while users still struggle with the task; the two are linked by evidence, not by definition.
